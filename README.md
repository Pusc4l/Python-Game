# 🎮 Python Arcade Hub - Deluxe Edition

A classic Python arcade mini-game collection built using the **Pygame** library. This project features a theme system (Dark/Light Mode), adjustable difficulty settings, and a high score tracker.

---

## 🕹️ Available Games
1. **Snake**: The classic snake game where speed adapts to the selected difficulty.
2. **Tic-Tac-Toe**: Play against an intelligent Bot with multiple difficulty levels.
3. **Pong**: A classic table tennis game head-to-head against the computer.
4. **Flappy Bird**: Navigate through pipe obstacles using gravity-based controls.
5. **Catch the Coin**: Catch falling coins using a movable basket.
6. **Memory Match**: A number card matching game to test your memory skills.

---

## 🚀 How to Run the Project

### Prerequisites
Make sure you have **Python** installed on your system (Python 3.8 or newer recommended).

### Installation Steps

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Pusc4l/python-arcade-hub.git
   cd python-arcade-hub
   ```

2. **Create and activate a Virtual Environment** (Optional but recommended):
   ```bash
   python -m venv venv
   # For Windows:
   venv\Scripts\activate
   # For Mac/Linux:
   source venv/bin/activate
   ```

3. **Install dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

4. **Run the Game**:
   ```bash
   python main.py
   ```

---

## ⚙️ Key Features
* **Theme System**: Toggle seamlessly between *Dark Mode* and *Light Mode*.
* **Difficulty Settings**: Choose between **Easy**, **Medium**, and **Hard** modes to customize your challenge.
* **High Score Tracker**: Keeps track of your best scores during your active gaming session.
